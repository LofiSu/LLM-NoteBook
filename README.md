# LLM-NoteBook

大语言模型学习笔记，涵盖原理、应用开发与工程实践。

[![GitHub stars](https://img.shields.io/github/stars/LofiSu/LLM-NoteBook?style=social)](https://github.com/LofiSu/LLM-NoteBook)
[![GitHub license](https://img.shields.io/github/license/LofiSu/LLM-NoteBook)](https://github.com/LofiSu/LLM-NoteBook/blob/main/LICENSE)

## 项目简介

本仓库按主题整理 LLM 学习笔记，内容包括基础概念、训练与推理、RAG 与 Agent 等应用，以及面试准备。

适合具备 Python 与深度学习基础、并希望继续学习大模型的读者。

## 快速开始

笔记为 Markdown，克隆后即可阅读。

```bash
git clone https://github.com/LofiSu/LLM-NoteBook.git
cd LLM-NoteBook
```

可按目录浏览，并对照文中示例动手验证。
